How it was built

The source file rits-consultation-deck.tex was compiled twice with XeLaTeX in TeXworks (MiKTeX), using the fonts and figures supplied beside it.

Reading the source

Each Beamer frame is one slide. Inside a tikzpicture, \node places a label or shape and \draw draws the connections between them.

Hosting
